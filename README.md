## 维护

页面为静态 HTML/CSS，没有构建依赖、脚本、广告或分析工具。GitHub Pages 从 `main` 分支根目录发布。

数据处理方式变化时，同时更新 `index.html`、`en.html` 及日期，然后提交到 `main`。更新政策时也须复核应用中的说明和 App Store 隐私申报。

支持信息或游戏操作变化时，同步更新 `support.html`、`support-en.html` 及页面日期。所有页面的页脚提供隐私政策与技术支持之间的链接。
