## 当前广告说明（2026-10-22）

应用的 Debug 与 Release 均开放可选奖励广告，当前仍为明确标注的 Google 官方测试广告，不产生真实收入。代码支持显式 live 配置与 UMP 请求许可流程，不代表已取得商业投放资格。公开政策区分进入奖励页的 UMP 隐私准备与点击观看后的 Google 广告 SDK 启动，并说明按需隐私选项、非个性化请求、SDK 数据处理及广告举报方式。

正式 ID、根站 app-ads.txt、发行地区和目标年龄、公开商店链接以及 AdMob 后台状态仍需核对。收款身份、税务与银行资料只在 Google 后台填写；银行入口可能受收入门槛影响。

## 维护

页面为静态 HTML/CSS，没有构建依赖、脚本、广告或分析工具。GitHub Pages 从 `main` 分支根目录发布。

数据处理方式变化时，同时更新 `index.html`、`en.html` 及日期，然后提交到 `main`。更新政策时也须复核应用中的说明和 App Store 隐私申报。

支持信息或游戏操作变化时，同步更新 `support.html`、`support-en.html` 及页面日期。所有页面的页脚提供隐私政策与技术支持之间的链接。
