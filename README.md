# AngleWings 隐私政策

本仓库仅用于发布 AngleWings（折光远航）的公开隐私政策，不包含游戏源码、游戏资源、签名材料或构建产物。

- 简体中文：<https://maoyayini.github.io/anglewings-privacy/>
- English: <https://maoyayini.github.io/anglewings-privacy/en.html>
- 发行者：刘政利（Liu Zhengli）
- 客服及隐私联系邮箱：liuzhengli0706@163.com

## 维护

页面为静态 HTML/CSS，没有构建依赖、脚本、广告或分析工具。GitHub Pages 从 `main` 分支根目录发布。

数据处理方式变化时，同时更新 `index.html`、`en.html` 及日期，然后提交到 `main`。更新政策时也须复核应用中的说明和 App Store 隐私申报。
