隐私政策

AngleWings 是一款离线单人飞行游戏，无需注册或登录。我们尊重你的隐私，并在此说明应用和本政策网页的数据处理方式。

1. 适用范围

本政策适用于 AngleWings（折光远航）当前的离线版本、与本应用有关的客服邮件，以及本隐私政策网页。

2. 游戏中的数据处理

应用不主动收集或向开发者、第三方服务器上传个人信息或游戏数据，不包含广告、用户追踪、统计分析或第三方 SDK，也不提供远程账号、云存档、聊天或联网排行榜。

金币、经验、关卡及分数纪录、武器等级、航舰与僚机的拥有和装备配置保存在设备的应用沙盒中，仅用于恢复本地游戏进度。应用可能保留上一份有效存档及损坏存档的本地副本，用于存档恢复；这些文件不会由应用上传。

应用不请求相机、麦克风、定位、通讯录或广告标识符权限。当前没有真实金钱购买或应用内购买；游戏金币通过游玩获得。

3. 数据共享与第三方服务

我们不出售、出租或将游戏数据用于广告，也不通过应用将这些数据共享给第三方。

Apple 操作系统、App Store、设备诊断和设备备份可能按照其自身政策及你的设置处理数据；这些属于相应平台服务。应用是否被纳入系统或云端备份，取决于设备及备份设置。AngleWings 本身不提供跨设备同步。

4. 你主动发送的客服邮件

如你主动向我们发送邮件，我们会收到你的邮箱地址、问题描述以及你选择提供的附件或其他信息，仅用于回复、排查和处理你的支持或隐私请求，不用于广告营销。使用基本游戏功能不需要发送邮件。

邮件通过你选择的邮件服务及收件邮箱服务处理，并受相应服务的政策约束。请勿发送密码、身份证件或与问题无关的敏感信息。应用不会自动发送邮件、存档或诊断数据。

我们仅在处理请求及必要后续沟通所需的期间保留相关邮件；如法律要求保留，则按要求保留必要信息。你可以通过下方邮箱请求查阅、更正或删除你主动提供的信息，或撤回对后续自愿提供信息的同意；我们会在合理核实请求后，按适用要求处理。

5. 本地存档的保存与删除

本地存档保留在设备上，供你继续游戏。在系统中选择“删除 App”会删除应用的本机存档；“卸载 App”可能保留应用文稿和数据。系统或云端备份中的副本，需要通过相应系统或备份设置管理。恢复备份可能恢复此前的游戏数据。

开发者不持有远程游戏账号或存档，因此没有远程账号注销流程，也无法代你读取、恢复或删除设备上的游戏进度。

6. 未成年人隐私

应用不会主动收集包括未成年人在内的用户个人信息。未成年人如需发送客服邮件，应由监护人协助，并避免提供不必要的个人信息。监护人如认为我们收到不当提供的未成年人信息，可通过下方邮箱联系并请求删除。

7. 访问本隐私政策网页

本网页由 GitHub Pages 托管。访问网页时，GitHub 会为安全目的记录并存储访问者的 IP 地址；相关处理请参阅 GitHub 隐私声明及 GitHub Pages 说明。

本网页没有添加广告、分析脚本、追踪器或表单，不会接收或上传你的游戏存档。打开本网页需要联网，离线游戏功能不依赖网页访问。

8. 政策变更

如应用的数据处理方式发生变化，我们会更新本政策及生效日期，并按适用要求提供通知、取得必要同意和更新商店隐私申报。未来版本的数据处理方式以相应版本的政策说明为准。
